# Jus-Lernapp

Lernapp fürs Jusstudium (österreichisches Recht): Lehrbücher, Transkripte, Altklausuren und OGH-Urteile aus Google Drive, Lernplan, Wissensabfrage, Falltraining und mündliche Prüfungssimulation.

Wird über Netlify veröffentlicht (die Datei `_redirects` leitet RIS-Abfragen weiter). Einrichtung: siehe `ANLEITUNG.txt` bzw. in der App unter „Einrichtung“.
